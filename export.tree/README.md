raw data for hippocampal vascular MRI study

describe:
1. sub-XX_ses-XX_T1w.nii.gz is the anatomical image collected by MP2RAGE

3. sub-XX_ses-XX_task-rest_acq-asl_run-01_desc-cbf/control.nii.gz in derivatives folder is the custom reconstructed CBF/control images collected by ASL
4. sub-XX_ses-XX_task-rest_run-01_bold/cbv.nii.gz is the BOLD/VASO image collected by SS-SI VASO
